## 个性化页新增「玻璃效果」总开关（默认开，关闭后回落到 Material 原生控件）

### 设计
- **持久化**：照抄 `ThemePreferences` 模式（SharedPreferences）。新建 `ui/glass/GlassState.kt`：`object GlassPreferences`（prefs 文件 `glass_prefs`，键 `glass_enabled`，默认 `true`）+ `val LocalGlassEnabled = staticCompositionLocalOf { true }`。
- **状态下发**：`MainScreen` 读取 `GlassPreferences` 进 `remember` 状态，经 `CompositionLocalProvider(LocalGlassEnabled provides …)` 下发（与 `LocalThemeMode` 并列）；`onGlassChanged` 回调写入持久化并传给 `PersonalizationScreen`。
- **回落方式**：所有玻璃组件**内部**判断 `LocalGlassEnabled.current`，false 时渲染标准 Material3 组件 → 调用点零改动。玻璃关 = `drawBackdrop`/blur/lens/vibrancy/采样路径完全不执行，渲染开销降到普通 Material UI。

### 改动清单
1. **新建 `ui/glass/GlassState.kt`**：`GlassPreferences`（get/set）+ `LocalGlassEnabled`。
2. **`ui/glass/GlassSwitch.kt`**：现有 `!enabled → Material Switch` 分支合并为 `!enabled || !LocalGlassEnabled.current → Switch`（颜色不变）。
3. **`ui/glass/LiquidButton.kt`**：关闭时渲染 M3 `Button`（`enabled`/`modifier.height(height)`/`Capsule` 形/`containerColor.copy(alpha=1f)`/`contentColor`，content RowScope 兼容），保留现有 8 处调用语义（含 enabled、height=40/48dp）。
4. **`ui/glass/LiquidFAB.kt`**：关闭时渲染 M3 `FloatingActionButton`（`size`/实色化 `containerColor`/`contentColor`，content BoxScope 兼容）。6 个页面 SpeedDialFAB 零改动自动回落（含单按钮降级态、展开态主钮、40dp 图标圆钮）。
5. **`ui/glass/LiquidSlider.kt`**：关闭时渲染 M3 `Slider`（`value/onValueChange/valueRange` + primary/surfaceVariant 色）。
6. **`ui/screens/boxgrid/BoxGridScreen.kt`**（缩放条区域 ~360-408 行）：`LocalGlassEnabled.current` 为 false 时把外层 `drawBackdrop` 玻璃胶囊换成普通圆角 Box（surfaceContainerHigh），配合 5 的 Slider 回落。
7. **`ui/MainScreen.kt`**：
   - 读入 glassEnabled 状态 + CompositionLocalProvider 下发；`onGlassChanged` 回调（写 `GlassPreferences`）传给 `PersonalizationScreen`。
   - `FloatingBottomNav` 内分支：开→现有 `LiquidBottomTabs`；关→标准 M3 `NavigationBar` + `NavigationBarItem`（icon/label/selected 用现成 `tabConfig` 数据），悬浮 Box 布局保留。
   - NavHost 的 `.layerBackdrop(appBackdrop)` 改为 `if (glassEnabled)` 条件挂载（关闭后不再逐帧记录采样层）。底栏调用仍传入 `backdrop`（分支内忽略，组件签名不动）。
8. **`ui/screens/settings/PersonalizationScreen.kt`**：「界面」分组置顶新增 `SettingsSwitchCard`（icon `Icons.Filled.BlurOn`，title「玻璃效果」，subtitle「关闭后恢复原生控件样式并降低渲染开销」，`checked = LocalGlassEnabled.current`，`onCheckedChange = onGlassChanged`，新增参数 `onGlassChanged: (Boolean) -> Unit = {}`）。此开关自身正是 `GlassSwitch`，玻璃关闭后它自动回退原生 Switch，显示正常。
9. **`strings.xml`**：新增 `personalization_glass_effect`、`personalization_glass_effect_subtitle`。

### 验证
- 仅 `./gradlew :app:assembleRelease`（不打 debug 包）→ 产出 `app-release.apk`。
- 无编译错误即可交付；代码层自查 6 处调用面（SpeedDialFAB 3、SampleEdit 4、ImageCleanup 3、Ocr 2、About 1、设置开关 6）分支完整性。

### 风险
- M3 `NavigationBar` 在悬浮 Box 内的观感（容器色/圆角），接受为「关玻璃后的朴素形态」。
- FloatingActionButton 的 content 槽位 receiver 需与 `BoxScope` 兼容（material3 版本为 BoxScope，无需调整）。
- 状态关闭仅影响渲染路径，路由/选中态/动画状态逻辑零改动。
